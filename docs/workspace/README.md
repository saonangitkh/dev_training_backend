# Event Tickets

| Folder | What |
|---|---|
| [`backend/`](backend/README.md) | Event Tickets API: Spring Boot 4.1 · Java 25 · PostgreSQL · JWT |
| [`android/`](android/README.md) | Android app: Kotlin · Jetpack Compose · MVVM |
| [`docs/`](docs/README.md) | Homework briefs and reference links for both projects |

## Quick start

```sh
cd backend
docker compose up -d --build     # PostgreSQL + API on http://localhost:8090
```

Then open `android/` in Android Studio and run the app on an emulator.
